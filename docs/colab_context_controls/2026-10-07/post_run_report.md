## Limits and interpretation

H1's registered acceptance contrast is positive (+2), but heterogeneous and insufficient to establish an isolated date mechanism. Both enriched conditions increase explicit acceptance and reduce corrections relative to bare counts for this fixed design. This is consistent with a broader added-context problem; F's seventeen non-corrections show that the observed consequence need not be explicit false endorsement. Token-length equality rules out unequal token counts between these specific D/F prompts, but does not equate semantics, milestone types, explanatory plausibility, lexical content or attention allocation. It does not distinguish added semantic content from extra length relative to bare counts.

One fixed temporal template and one office/logo template, fixed years, six correlated synthetic entity blocks, one greedy answer per prompt, observed-history-informed design, fixed technical configuration and an unblinded AI-assisted audit limit generalization. This is not independent held-out confirmation, repeated sampling, an unquantized baseline or an INT8 comparison. No new human confirmation is assumed from the file upload. The preceding date study retains its original 7/24 versus 1/24 counts and selected five-row human follow-up; these new prompts are a distinct study and are not pooled with it.

Original Phase 3B prereg `phase3b-preregistered` / `ed64ba8`, raw results, dataset, evaluator and frozen automated counts remain unchanged: false-premise 16 PASS / 6 POTENTIAL / 2 DETECTED plus six PASS controls, overall 22 / 6 / 2. These automated results are distinct from all subsequent AI-assisted semantic annotations.
